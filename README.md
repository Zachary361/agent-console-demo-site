# Agent 工作空间

公开体验：[打开 Demo](https://zachary361.github.io/agent-console-demo-site/index.html)。

包含 VOC 评论打标、款式改善与工单、多语言智能客服，以及客服多 Agent 总控和七个专职 Agent（含语言润色）。在 Agent 治理选择 Agent，打开画布，填入场景参数运行。

GitHub Pages 使用浏览器内的规则执行器，无需登录或连接本地服务。建议使用新版 Chrome / Edge。会话、图版本、人工确认和运行记录保存在当前浏览器的 IndexedDB，同站点多个页签共享工作区；关闭所有页签后未完成的运行会在下次打开时提示重试。换设备或清除站点数据不会保留这些记录。

当前未调用真实语言模型；客服回复和 PLM 任务均为演示记录，不向客户发送消息或写入真实 PLM。图片、未知语言和有冲突的标签保留人工复核。图生视频需要另行部署视频服务。
