用原画布建立图生视频 Agent

无需 SSO。图生视频与欢迎语演示位于同一 Agent 注册表。当前是图片镜头动效演示，未接 AI 模型。

新建与编排

  1. 进入「Agent 治理」→「新建 Agent」，填写 code（如 demo.product_video）和名称，选择「图生视频模板」或「空白画布」。
  2. 下一步确认输入输出契约，创建后点击「在画布打开」。
  3. 选择模板会得到可编辑的「开始 → 图生视频 → 结束」。空白图需在工具栏添加图生视频节点，点击原开始到结束的连线，在下方摘要删除旧连线，再从节点输出圆点拖至下一节点。看不到节点时点「适应」。
  4. 双击图生视频节点，设置 3/5/8 秒、横屏/竖屏/方形、推近/平移/静态，输出路径为 variables.video。双击结束节点，来源路径也填 variables.video。
  5. 点击「校验」→「保存草稿」。

运行与结果

  1. 点击「运行参数」，上传 PNG/JPEG（≤4 MB、边长≤4096）或点击「使用示例图片」。
  2. 在输入 JSON 中填写 prompt，保留 image 占位符，点击「运行编排」。
  3. 在原运行检查器查看节点进度、日志及结果，播放并下载 MP4。「查看运行追踪」可以查看同一次运行的输入输出、视频和重试。

版本与数据

画布试运行执行当前节点和连线快照，时长与画幅来自视频节点配置。保存草稿不覆盖旧 Agent 版本；需要固定新图时，在 Agent 治理中创建新版本。重试沿用原运行快照。

新 Agent、编排和任务保存到当前浏览器对应的匿名后端工作区。刷新后仍在；清除站点数据会失去入口。图片、视频上传并保存于演示后端，不同工作区隔离。每工作区最多 20 条历史任务，不自动过期。

演示范围

后端实际按图执行、排队和生成 MP4。提示词仅记录，不会生成新主体动作。支持顺序图和一个视频节点。未接入的生产发布、评测、知识库、审核、基本信息编辑和删除 Agent 等操作禁用。欢迎语原示例仍由浏览器规则运行。

当前后端是临时演示通道，依赖演示电脑和进程运行；连接失败可在 Agent 治理点击「重新连接」。长期使用需部署到常驻服务器。顶部「重置欢迎语示例」只重置浏览器欢迎语数据。
