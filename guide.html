脱敏演示使用说明

这是原型前端的脱敏演示版。全部示例为虚构数据；没有原站账号、业务记录、模型密钥或后端执行引擎。

跑通一个示例

  1. 打开「编排画布」，当前 Agent 为「欢迎语演示」。
  2. 点击「运行参数」，输入 {"name":"演示访客"}。
  3. 点击「运行编排」，查看开始、模拟模型输出、结束三个节点。
  4. 进入「运行追踪」，选择本次运行，查看每个节点的输入输出。
  5. 拖动节点调整布局，点击「保存草稿」，刷新后会保留布局。

可做与未接入

可浏览原型各模块、编辑顺序编排、执行本地模板示例、验证输入、保存测试用例、回放运行记录。演示执行只支持 start / llm / end；llm 只替换 mock_output 中的 {{input.name}}，不会调用模型。

自然语言生成 Agent、企业登录、技能调用、知识上传、人工审批、评测、触发器和版本发布需要真实后端，本版禁用相关操作。页面中的原系统技术描述仅用于展示设计。

数据与重置

图、测试用例及最近 30 次模拟运行存放在当前浏览器本地。顶部「重置示例」只清除本演示前缀的数据。不应输入真实凭证或业务资料。

本地启动

在项目目录执行 python3 -m http.server 8765 --bind 127.0.0.1，访问 http://127.0.0.1:8765。请使用桌面浏览器。
