图生视频 Demo 使用说明

无需 SSO 或 GitHub 登录。已有图生视频 Agent，支持新增自己的 Agent。当前视频为图片镜头动效演示，未接入真实 AI 模型。

生成第一个视频

  1. 进入「图生视频任务」，选择「图生视频 Agent」。
  2. 点击「用示例图」，或上传 PNG / JPEG（最大 4 MB，边长不超过 4096）。
  3. 填写提示词，选择 3 / 5 / 8 秒、画幅与镜头效果。
  4. 点击「提交生成任务」，右侧自动显示排队、生成和完成状态。
  5. 选择完成的任务，即可播放并下载 MP4。

创建自己的 Agent

进入「我的 Agent」→「新建 Agent」，填写名称、用途说明和默认提示词。保存后点击「创建视频任务」。刷新页面后仍保留在当前工作区。

任务管理

支持搜索、状态筛选、查看进度与日志、取消任务、再生成一次，以及删除历史任务。重试会创建新任务，保留原记录。每个工作区最多保留 20 个任务，同时最多运行或排队 3 个。

演示边界

后端实际保存数据、排队并编码 MP4。提示词仅保存，画面运动由「镜头」选项决定，不会生成新的主体动作。企业登录、知识库、审核等原型模块仍未接入。

数据与可用性

图片和视频上传并保存于演示后端，不同浏览器工作区相互隔离。凭证保存在当前浏览器；清除站点数据会失去原工作区入口。删除任务会清理没有其他任务引用的文件。

当前在线后端为临时演示通道，依赖演示电脑和进程持续运行。若显示后端不可达，请稍后点击「重新连接」。长期使用需部署到常驻服务器。

原欢迎语示例

「编排画布」仍可执行欢迎语模拟。顶部「重置欢迎语示例」只重置旧版浏览器示例，不会删除视频工作区。
